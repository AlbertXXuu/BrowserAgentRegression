# Studio viewport evidence

These screenshots and [`viewport-audit.json`](viewport-audit.json) record the bounded
BrowserAgentRegression Studio closure check for software `1.1.0-candidate`. The checkpoint view is
derived from the immutable v1.0 calibration; the screenshots and browser audit are presentation
validation, not new research evidence.

The audit covers 900, 1024, 1280, 1440, and 1600px widths, the shared Header contract, target
sizes, keyboard focus, the reference/candidate checkpoint values, the first-divergence label, and
one in-memory 12-attempt deterministic demo.
