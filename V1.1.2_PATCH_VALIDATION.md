## Observed problem and release meaning

At supported desktop widths, the three checkpoint nodes in one Studio row could acquire different
heights, and the first-divergence annotation and long checkpoint IDs could collide with adjacent
content. The defect was reproduced from the owner-provided Studio screenshot and measured in a real
Chromium layout.

`v1.1.2` is a UI-only maintenance patch. It gives every node in a row the same grid geometry, keeps
marker, percentage and annotation tracks aligned, and introduces valid wrap opportunities inside
checkpoint IDs. It does not change tasks, variants, drivers, checkpoints, evidence accounting,
fixtures, schema, protocol, dependencies or research claims.

## Validated changes

- Preserve the canonical AlvenX product header, wordmark, palette and static product canvas.
- Render a reserved annotation track in every checkpoint node so popup-blind nodes remain aligned
  whether or not they contain the first-divergence label.
- Wrap checkpoint IDs at their existing dot separators while preserving their exact accessible and
  textual value.
- Add a browser regression test at `900`, `1024`, `1280`, `1440` and `1600` CSS pixels that checks
  child containment, equal row heights, aligned internal tracks and absence of adjacent overlap.
- Update current software identity and public quick-start wording to `v1.1.2` while retaining
  evidence identity `v1.0.0`.

## Historical evidence and README media

The immutable `v1.0.0` evidence, schema, fixtures and protocol are unchanged. The historical
`FINAL_RELEASE_AUDIT.md`, annotated tags and GitHub Releases are not rewritten.

`docs/assets/browser-agent-regression-demo.gif` shows the older pre-checkpoint orbit presentation;
it does not show the checkpoint-node defect addressed by this patch. No deterministic generator for
that GIF exists in the repository, so the asset is retained unchanged and is not used as `v1.1.2`
layout evidence. The browser regression test is this release source's executable layout evidence.
